# Horizon 本地 Web 控制台产品需求

本次为 Horizon 增加个人使用的观测与控制台：用户可以查看真实运行状态和阶段条目、阅读历史速递、发起或取消运行、调整信息源与筛选规则，并在网页管理微信连接。范围依据用户完整开发委托及所附功能蓝图冻结；交付止于本地运行和浏览器验收。

| 需求版本 | 需求状态 | 目标 Release | 确认依据 |
|---|---|---|---|
| 1 | `FROZEN` | `web-console-local-v1` | 2026-11-04 用户指定 FastAPI + React（Tailwind），授权整套开发、本地测试与文档初始化 |

产品上下文见 [PRODUCT.md](../../PRODUCT.md)，视觉规范见 [根 DESIGN.md](../../DESIGN.md)。本文件定义需求与验收，实际进度及结果分别由 [PROGRESS.md](PROGRESS.md) 和 [VERIFICATION.md](VERIFICATION.md) 维护。

## 1. 产品概述与背景

Horizon 已有 CLI 与 MCP 服务、AI 评分、过滤、深度补充和 Markdown 速递能力。日常使用仍需查看终端和文件，配置与微信连接也分散在不同入口。控制台把这些操作集中到本地浏览器，同时复用既有业务服务。

成功定义是用户能通过界面完成下述操作并理解结果。历史缺失的指标、未接管的外部调度、尚未验证的微信连接均应显式表达，不以演示数据或推测填补。

## 2. 目标与非目标

- 覆盖个人本机使用、真实文件数据观测、受控后台运行、配置编辑及微信连接管理。
- 采用 FastAPI + React + Tailwind，前端构建后由后端单端口提供，默认地址为 `http://127.0.0.1:8765`。
- 不增加数据库、多用户系统、云部署、内置定时器或信息源市场；不接管外部 cron、launchd 或 GitHub Actions。
- Web 运行只生成和保存结果，不自动发送邮件、微信或 webhook；用户可在历史速递预览并确认手动推送微信；浏览器验收不触发真实付费 AI 调用。

## 3. 目标用户与场景

唯一使用者是本机项目所有者。用户打开概览确认是否有任务运行，从运行详情查看哪些条目通过筛选，再阅读生成的速递；需要时调整信息源、阈值和分类配额，发起下一次运行。微信页用于连接和诊断会话，不承担消息发送测试。

以下均为本次核心交付，优先级为 P0；没有单独承诺的后续增强项。

## 5. 核心行为与验收标准

### 5.1 REQ-001：真实状态概览

打开概览读取真实配置、运行工件、历史速递和微信会话摘要。不存在运行工件时展示空状态并提供运行入口；已有历史速递仍可阅读。Token 和耗时仅展示被记录的指标，缺失显示“未记录”。外部定时任务状态显示未接管，不宣称每日固定时间已启用。微信“已保存会话”与经过外部服务确认的连接状态不得混淆。

| 验收 | 给定—当—则 | 检查入口 |
|---|---|---|
| AC-001 | 给定只有历史速递且没有运行目录，当打开概览，则能访问速递，并看到运行空状态及未记录指标。 | 概览、`GET /api/overview` |
| AC-002 | 给定已记录运行计数、耗时和 Token，当打开概览，则指标与工件一致；缺失字段不会显示为伪造的零或演示数值。 | 临时运行工件、概览 |
| AC-003 | 给定未接管外部调度，当打开概览，则明确展示该边界，不显示虚假的活动调度。 | 概览 |

### 5.2 REQ-002：运行与阶段观测

用户从运行历史选择一条运行，再切换原始、评分、筛选、补充四个阶段。界面展示可用阶段及条目，支持搜索和评分筛选；长标题可完整查看。条目详情展示来源、链接、分类、评分与现有分析内容。比较前后阶段推断的淘汰原因必须标注“推断”，不能当作原始决策日志。

工件缺失、阶段尚未完成和空条目分别给出相应提示。访问不存在运行或非法阶段应收到明确错误，不能读取任意服务器文件。旧 CLI 未写阶段工件的运行不伪造为可追溯历史。

| 验收 | 给定—当—则 | 检查入口 |
|---|---|---|
| AC-004 | 给定包含四阶段的运行，当选择各阶段并搜索、调整评分筛选，则列表与筛选结果一致，可查看条目分析。 | 运行详情、阶段 API、伪工件 |
| AC-005 | 给定评分阶段有条目但筛选阶段未保留，当查看原因，则明确区分原始分析与推断原因。 | 运行详情 |
| AC-006 | 给定缺失或非法工件标识，当访问对应地址，则显示可恢复错误，不泄露服务器路径或其他文件内容。 | API 路径校验测试、界面错误态 |

### 5.3 REQ-003：历史速递

读取现有 `data/summaries/horizon-日期-语言.md` 和可用运行摘要，按日期与语言定位，正文保留 Markdown 标题、列表和链接。用户可下载 Markdown 原文。摘要中的 HTML 或脚本不得作为可执行内容注入页面，外部链接使用安全打开方式。

| 验收 | 给定—当—则 | 检查入口 |
|---|---|---|
| AC-007 | 给定中英文历史速递，当切换日期、语言或选择记录，则显示对应正文，下载内容与原文件一致。 | 历史速递页、摘要 API |
| AC-008 | 给定无摘要或包含恶意 HTML 的摘要，当打开阅读页，则提供空状态或安全的文本渲染，不执行脚本。 | 临时摘要、浏览器 |

### 5.4 REQ-004：运行控制与日志

用户选择近 12、24 或 48 小时，发起后台任务。运行会调用现有流水线服务，并记录阶段状态、耗时和 Token。界面通过实时日志和状态刷新展示进度；断开页面不会主动终止后台运行。CLI 与 Web 共享运行锁，已有任务运行时不能再次启动或写配置。

| 当前状态 | 用户动作或事件 | 允许结果 |
|---|---|---|
| 空闲 | 发起运行且成功取得锁 | 进入运行中，返回运行标识 |
| 运行中 | 再次发起运行 | 明确提示冲突，原任务继续 |
| 运行中 | 取消 | 请求取消，保留已生成工件并释放资源 |
| 运行中 | 阶段异常 | 记录失败并保留已有工件，可查看错误 |
| 运行中 | 最后阶段完成 | 完成并保留摘要及元信息 |
| 完成、失败或已取消 | 查看历史或重新发起 | 历史保持可读，新运行使用新标识 |

取消不能撤销已经发生的外部请求或费用。若完成先于取消生效，界面以最终任务状态为准，不把已完成结果覆写为取消。

| 验收 | 给定—当—则 | 检查入口 |
|---|---|---|
| AC-009 | 给定伪服务且空闲，当选择时间窗并启动，则返回运行标识，依次显示阶段状态和日志，完成后可读取摘要。 | API 集成测试、浏览器 |
| AC-010 | 给定 CLI 或 Web 已持锁，当重复启动或保存配置，则收到冲突反馈且没有第二个任务或配置覆盖。 | 共享锁测试、运行中界面 |
| AC-011 | 给定可取消任务，当取消或模拟阶段异常，则最终状态正确、锁被释放、已有工件及日志仍可读取。 | 任务生命周期测试 |
| AC-012 | 给定日志连接中断，当恢复连接，则能重新获取日志与当前状态，不因断线重复启动任务。 | SSE 和日志读取测试、浏览器 |

### 5.5 REQ-005：配置管理

用户可启停、增加、编辑和删除已支持的信息源，并调整评分阈值、分类配额等筛选配置。提交前应校验字段和现有配置模型；评分范围为 0–10，配额遵循已有正数约束。操作失败保留表单内容并显示可理解的错误。

配置从原始 JSON 做白名单局部修改，保留未知但未编辑的字段、`${ENV}` 引用和凭据。读取响应脱敏，脱敏占位符不得写回原配置。保存携带读取时的 revision；检测到外部改动时拒绝覆盖，提示重新加载。保存以原子写完成，并创建独立备份，不覆盖接手时用户已有的备份文件。

| 验收 | 给定—当—则 | 检查入口 |
|---|---|---|
| AC-013 | 给定合法配置，当启停或增删改信息源并保存，则重新读取反映变更，阈值和配额遵循校验规则。 | 配置页、配置 API |
| AC-014 | 给定配置包含环境变量和凭据，当读取并只修改筛选项，则响应不泄密，保存后未编辑的引用和凭据保持原值。 | 临时配置往返测试 |
| AC-015 | 给定过期 revision、非法字段或原子写失败，当保存，则明确报错，原配置仍完整且不会被无效输入覆盖。 | 配置冲突与写失败测试 |

### 5.6 REQ-006：微信连接

微信页展示是否启用、会话是否存在、是否已收到首条消息上下文，以及剩余回复额度的本地估算。用户主动请求登录后显示二维码，区分等待扫码、已扫码、需要确认、等待首条消息、就绪、过期和失败等可观察状态；允许取消和重新请求。确认登录后引导用户在微信中给机器人发送首条消息，再刷新上下文。

二维码内容在本机生成展示，服务端会话凭据不返回浏览器。登录、刷新均不发送消息、不消耗回复额度；“已保存会话”不等于当前外部连接已实时验证。

| 验收 | 给定—当—则 | 检查入口 |
|---|---|---|
| AC-016 | 给定伪微信服务，当发起登录并推进扫码状态，则页面显示二维码及对应反馈，可取消、过期后重新开始。 | 登录状态机测试、微信页 |
| AC-017 | 给定已确认但缺少首条消息上下文的会话，当刷新后收到新上下文，则状态变为就绪，额度按本地规则估算并标注。 | 会话刷新测试 |
| AC-018 | 给定包含令牌的会话和外部错误，当读取状态、日志或错误，则不包含会话令牌；登录和刷新不会调用发送接口。 | 脱敏测试、伪服务调用记录 |

## 6. 交互与界面要求

界面采用操作型控制台，中文导航和反馈，视觉细节由 [根 DESIGN.md](../../DESIGN.md) 维护。

| 界面 | 空状态 | 加载状态 | 错误状态 | 极限与恢复 |
|---|---|---|---|---|
| 概览与运行 | 无运行记录仍展示真实历史速递入口 | 明确正在获取状态 | 给出重试入口，保留已知状态 | 长标识不撑破布局；移动端可操作 |
| 阶段条目 | 区分尚未生成与结果为空 | 切换阶段时反馈读取中 | 指明不可读取阶段 | 长标题换行或详情展开，搜索无结果可清空条件 |
| 历史速递 | 明确尚无该日期或语言的摘要 | 正文读取反馈 | 保留选择，允许重试 | Markdown 长链接、代码块不会造成页面横向溢出 |
| 配置 | 无该类来源时可添加 | 保存期间阻止重复提交 | 保留编辑值，冲突提示重新加载 | 运行中禁止保存，删除需明确操作 |
| 微信 | 未连接时提供登录入口 | 展示扫码或上下文等待阶段 | 明确过期、取消和外部失败 | 可取消或重新开始；额度是估算 |

所有可交互元素支持键盘操作和可见焦点；图标按钮有可访问名称。颜色之外仍可读到任务和错误状态。桌面与窄屏均需实际浏览器检查。

## 7. 限制、非功能需求与跨功能边界

| 类别 | 要求与判定口径 | 验证入口 |
|---|---|---|
| 本机边界 | 默认仅监听环回地址，检查 Host、Origin 和写请求来源，不提供公网多用户服务承诺 | 后端请求测试 |
| 数据与隐私 | 工件与会话路径由服务端固定；配置、错误和日志脱敏；只访问允许标识的文件 | AC-006、AC-014、AC-018 |
| 并发一致性 | CLI 与 Web 使用同一运行锁；任务运行与配置保存互斥 | AC-010、AC-015 |
| 原系统兼容 | CLI、MCP 和既有配置仍可使用；已有用户工作树改动保持完整 | 受影响回归、交付 diff |
| 外部服务验证 | 自动验收使用临时数据和伪服务，真实模型与微信扫码由用户最终验收 | 验证记录限制 |

不存在历史指标、工件或调度信息时按已知边界显示，不通过扫描脚本推定任务已实际启用。

## 8. 统计与运行数据

不接入外部埋点或分析平台。仅为用户本机观测记录运行状态、阶段计数、耗时、Token 与必要日志；错误和日志遵循脱敏要求。既有数据不迁移、不伪造补齐。

## 9. 待决问题与风险

Open Questions：`None`。功能范围与本地交付已由本次完整委托覆盖；技术内部选择由实施方案维护。

| 风险 | 影响与处理 | 跟进入口 |
|---|---|---|
| 外部微信接口变化或需人工验证 | 伪服务覆盖本地状态机，真实登录保留用户验收边界 | AC-016–AC-018、验证记录 |
| 任务已发出的请求不能撤销 | 取消保留部分工件，状态和日志说明终止结果 | AC-011、方案设计 |
| 用户在其他入口编辑配置 | revision 拒绝覆盖，要求重新加载再编辑 | AC-015 |
| 旧 CLI 历史缺少阶段与指标 | 如实展示缺失；可观测运行从本次 Web 入口开始累积 | AC-001、AC-002 |

## 2026-11-05 本地使用反馈补充

用户授权修复停更 RSS 与正文 DNS，并增加 Web 报告的微信推送入口。验收要求：同日报告更新后可在历史页读取最新正文；手动推送先预览分段与额度，确认后发送完整报告；过期版本、会话变化、额度不足与重复发送必须拦截，失败显示实际已确认段数。自动验收继续使用伪微信，不发送真实通知。
