# Horizon 本地控制台使用指南

控制台把观测、运行记录、历史速递、配置和微信连接集中在本地浏览器。数据继续保存在 Horizon 项目中；Web 发起的运行会访问已配置的信息源和模型，只生成并保存速递，不自动发送邮件、微信或 webhook。

## 启动与停止

在项目根目录执行：

```sh
npm --prefix web ci
npm --prefix web run build
uv run horizon-web --host 127.0.0.1 --port 8765
```

随后打开 `http://127.0.0.1:8765`。前两步安装锁定的前端依赖并构建页面，后端会通过同一端口托管 `web/dist`；未修改前端且构建产物仍在时，后续只需运行第三条命令。首次启动由 uv 安装 Python 依赖；本项目要求 Python >=3.11，前端工具需使用满足 Vite 版本要求的 Node.js。

控制台使用原有 `data/config.json` 和项目环境变量。若尚未配置 Horizon，先运行 `uv run horizon-wizard`；密钥仍在本地配置及环境中维护。页面不会提供模型密钥编辑框。

自定义数据或配置位置可使用：

```sh
uv run horizon-web --host 127.0.0.1 --port 8765 \
  --data-dir /绝对路径/数据目录 \
  --config /绝对路径/config.json \
  --runs-dir /绝对路径/阶段工件目录
```

`--config` 默认取数据目录下的 `config.json`，`--runs-dir` 默认取其 `mcp-runs`。相同数据目录的 CLI/Web 才共享同一把锁。监听地址只允许 `127.0.0.1`、`localhost` 和 `::1`，不提供公网或局域网多用户访问。

在启动终端按 `Ctrl+C` 停止服务。正常退出会取消本进程正在执行的流水线或微信登录，并保留已写工件；关闭浏览器标签页只断开界面连接，不会停止后台运行。强制终止留下的 Web 运行会在下次安全恢复时标为“已中断”。

## 日常操作

1. **观测台**：检查本次任务、最近运行和速递、信息源及微信状态。历史 Token 或耗时缺失时显示未记录；外部调度不由控制台接管。
2. **运行一次**：选择 12/24/48/72 小时或 7 天、速递语言以及是否深度补充，再开始运行。此操作可能产生已配置模型的费用。使用默认语言时沿用保存的配置。
3. **运行记录**：选择运行后切换采集、评分、筛选和补充，搜索条目、按来源/最低评分/保留状态过滤，并展开详情。未保留原因是工件比较推断，不是精确决策日志。
4. **运行日志**：查看实时或历史日志，搜索关键字、过滤级别、暂停自动跟随，或下载保留的日志。断线会重连；历史最多显示最近 2000 项，不能恢复已超出保留范围的内容。
5. **取消运行**：在当前运行详情发起取消，保留已产生的工件；已经发生的外部请求或模型费用不能撤回。
6. **历史速递**：按日期、语言和标题搜索选择报告，可按报告的二级标题筛选章节，并下载完整 Markdown 原文。旧 CLI 生成的摘要仍可在这里阅读。

浏览器显示时间按其本地时区格式化；摘要文件日期沿用现有流水线的 UTC 日期规则。相同 UTC 日期和语言的新速递会覆盖本地历史摘要文件，单次运行目录仍保留自身摘要。

## 配置编辑与备份

配置页分为信息源、筛选规则和服务配置。RSS 与 GitHub 列表可通过表单添加、修改、启停或移除；新条目默认停用。其他来源的频道、关键词等嵌套结构可通过“高级 JSON”编辑：先“应用到草稿”，再“保存配置”。高级输入尚未应用时不能直接保存。

筛选规则可以调整默认采集时间窗、处理配置、评分阈值、主题去重和分类配额；服务配置展示模型信息，并提供原有微信推送开关。这个开关同时控制 CLI 和历史页手动推送；Web 运行本身仍只生成速递。

配置保存后仅影响下一次运行。页面保留未保存草稿，并在离开或放弃时提示。流水线或微信登录占用数据锁时无法保存；等任务结束或取消后重试。外部编辑导致 revision 冲突时，服务拒绝覆盖，请保留需要的草稿内容再重新加载。

凭据和环境变量继续由本地文件维护。不要用新值替换脱敏占位符，网页会拒绝凭据变更。每次成功保存前，配置同目录会生成独立的 `config.json.web-UTC时间-随机后缀.bak`；不会覆盖已有 `config.json.bak`。需要恢复时先停止任务，把选定备份恢复到配置路径，再重新加载并验证。

如果多条私密订阅名称相同，而且网页脱敏后的 URL 也完全相同，删除、重排或编辑时会提示无法安全关联凭据并拒绝保存。请先在本地配置中给它们设置不同名称，再重新加载页面；这类失败不会修改配置或生成独立备份。

## 微信连接与报告推送

1. 进入“微信连接”，点击“获取登录二维码”；如果已有会话，可重新扫码连接。
2. 使用手机微信扫描页面二维码，在手机确认；页面要求验证码时，输入微信显示的验证码并提交。
3. 手机确认后，向机器人发送一条消息，例如“你好”，以建立回复上下文。页面会等待消息，之后也可点击“刷新消息上下文”。
4. 看到本地会话就绪后，在“配置 → 服务配置”启用微信推送并保存。
5. 进入“历史速递”，选择报告，点击“推送到微信”，检查分段和估算额度，再点“确认发送”。发送包含全部章节，不受当前章节筛选影响。

二维码或等待消息约 8 分钟后超时，可取消或重新获取。等待首条消息超时后已保存会话仍保留，发消息后刷新即可。扫码任务保存在当前服务内，重启后旧页面提示会话不存在时重新获取二维码。

“已连接”表示本地存在会话，“已就绪”表示具备本地回复上下文，不是持续在线探测。剩余额度为本地估算，以实际微信服务结果为准；向机器人发送新消息通常可更新上下文。登录、刷新和手动推送会持有共享锁，期间不能同时启动流水线或保存配置。发送失败会显示已确认段数；同一报告版本不会自动重发，部分失败或结果不明时先检查微信。

## 文件位置与兼容限制

| 位置 | 内容 |
|---|---|
| `data/config.json` | 原有配置，凭据可使用环境变量引用 |
| `data/config.json.web-*.bak` | Web 保存前的独立备份 |
| `data/.horizon-run.lock` | CLI 与 Web 的文件锁；锁文件存在不代表正在持锁 |
| `data/mcp-runs/{run_id}/meta.json` | 运行状态、计数、耗时、Token 和阶段耗时 |
| `data/mcp-runs/{run_id}/*_items.json` | 各阶段条目 |
| `data/mcp-runs/{run_id}/summary-语言.md` | 单次运行摘要 |
| `data/mcp-runs/{run_id}/web-logs.jsonl` | 脱敏持久化日志，按约 1 MB 尾部保留 |
| `data/summaries/horizon-日期-语言.md` | 按日和语言保存的现有历史速递 |
| `data/wechat-deliveries/` | 手动推送结果及防重复记录；不包含会话令牌 |
| `data/wechat_session.json` | 微信会话凭据，只由本机服务管理 |

使用 `--data-dir` 或 `--runs-dir` 时，以上相应路径随参数变化。旧 CLI 不写完整阶段工件，因此其摘要可以阅读，但不能补出过去的各阶段、Token 或耗时。既有 MCP 工件可读取，缺失的新指标保持未知。

CLI 与 Web 已接入共享锁；既有 MCP 的直接阶段调用和不使用这把锁的外部工具没有并发保护，使用相同目录时请错开操作。控制台不创建、读取或管理系统定时器，不能据页面推断 cron、launchd 或 GitHub Actions 已启用。原 CLI 按其配置仍可能发送外部通知，Web 行为不改变它的通知规则。

## 排错与接口入口

| 现象 | 处理方法 |
|---|---|
| 页面提示前端未构建 | 回到项目根执行 `npm --prefix web ci` 和 `npm --prefix web run build` |
| 端口已占用 | 停止占用进程或用 `--port` 选择其他端口，并访问相同地址 |
| 页面连接异常 | 确认后端仍在运行；检查启动终端，重新加载页面 |
| 配置无法读取或校验失败 | 检查 JSON、环境变量、分类引用；使用原有向导完成配置 |
| 显示其他任务运行中 | 等待任务结束；检查其他 CLI/Web 或微信扫码，必要时从其所属入口取消，不手动删除锁文件判断状态 |
| 配置已被更新 | 复制需要保留的草稿内容，重新加载后再编辑保存 |
| 私密订阅提示需设置不同名称 | 先在本地配置中为同名且脱敏 URL 相同的订阅设置不同名称，重新加载后再编辑 |
| 运行失败或中断 | 查看该运行日志和已有工件，修正信息源或模型配置，再发起新运行 |
| 旧运行没有日志或阶段 | 属于历史未记录数据；不能从摘要反推补齐 |
| 微信二维码/刷新失败 | 检查外部网络，重新扫码；若需首条消息，先在微信给机器人发消息 |
| API 写操作返回 403 | 浏览器必须同源；手动调用需 Origin 与 Host 一致且携带 `X-Horizon-Request: 1` |

本地健康检查为 `/api/health`，离线接口目录为 `/api/docs`，完整契约为 `/api/openapi.json`。完整调用方式见 [API.md](API.md)，开发及验收范围见 [PRD.md](PRD.md) 和 [VERIFICATION.md](VERIFICATION.md)。真实模型调用和个人微信账户由用户最终验收，伪服务测试不代表外部账户已连通。

历史速递按最近更新时间排列，同一天同语言保留最新版本，因此重新生成后份数可能不变。页面会自动读取新版本，也可点击“刷新归档”；各次运行的原始版本可在运行记录中查看。
